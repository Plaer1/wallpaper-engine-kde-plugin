# Eye-in-gear icon source

These six editable, standalone SVGs are vector interpretations of a circular eye reference. The palette variants reuse the same gear and concentric-eye geometry as the monochrome pair.

| Asset pair | Authored palette |
| --- | --- |
| `eye-gear-1-light.svg`, `eye-gear-1-dark.svg` | light: ink `#232629`; dark: cream `#F5EEE0` |
| `eye-gear-2-light.svg`, `eye-gear-2-dark.svg` | corresponding foreground plus gold `#D69E2E` for the eye ring |
| `eye-gear-3-light.svg`, `eye-gear-3-dark.svg` | foreground, cream `#F5EEE0`, and gold `#D69E2E`; highlights use the contrasting third color |

The shared design has eight broad gear teeth, a concentric eye ring, a dominant pupil, and two highlight points. Monochrome and two-color variants use transparent even-odd cutouts where needed. The three-color pair colors the highlights. There are no gradients, filters, bitmap embeds, external asset references, or background plate. Authoring previews and contact sheets are not runtime assets.
